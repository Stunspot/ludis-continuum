# Description

Ludis Continuum handles the creation, preparation, operation, and reconciliation of stateful tabletop role-playing campaigns. It develops settings, adventures, encounters, factions, NPCs, and playable material while keeping player-visible canon, GM secrets, rulings, consequences, and unresolved possibilities distinct. Campaign records remain coherent after unpredictable play and can be resumed or prepared for publication without erasing player agency. The Campaign Table keeps tonight's playable situation, ordered cues, near horizon, preparation, source status and explicit relationships visible while the GM works. Its world view follows incoming and outgoing links, exposes provenance, and compares connected material side by side. Night Routes and Patchwork World express the same governed ledger through distinct dark and dark woven working environments. A separately filtered player-reading candidate omits GM ledger metadata and private state; the GM still reviews the exact prose before sharing. The desk does not create a second virtual tabletop.

# Usage Notes

Copy the `.zip` from Additional Files to your chosen harness or Chat project, attach or reference it in chat, and say, `Install this Augment.` The prompt in this post is optional. It provides clean installation and onboarding.

- Tell it the game system and edition, premise, players and boundaries, established canon, current situation, and whether you are creating, preparing, running, or reconciling.
- Mark GM-only secrets and player-visible material clearly before sharing records or generated handouts.
- Dice tools, licensed rules content, VTT import and publication capabilities depend on your host and the rights you hold.

Public GitHub Repo: [ludis-continuum](https://github.com/Stunspot/ludis-continuum)

- Ask “Open Ludis,” or use the workspace Windows/macOS launcher; Python 3.10+ is required.
- Keep campaign-ledger v2 outside the installation in Documents/LudisContinuum or the external LUDIS_DATA_HOME folder. The desk and agent use that same canonical ledger.
- Capture proposals and use native GM promotion tools for active canon. Review the exact player-reading candidate before sharing; labels cannot detect prose spoilers.
- Use the Tonight stage, world relationships and capture alongside your existing table tools; the desk is not a new VTT. Desktop shortcuts require consent.
