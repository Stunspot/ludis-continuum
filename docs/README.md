# Ludis Continuum project site

This directory is the static GitHub Pages source for **Ludis Continuum**.

- `index.html` contains the semantic landing page.
- `style.css` contains responsive, keyboard-visible, reduced-motion-aware presentation.
- `assets/ludis-continuum-hero.png` is a generated 1600×900 PNG stored in the repository.
- `.nojekyll` asks GitHub Pages to serve the files directly.

The site uses no JavaScript, analytics, downloaded webfont, framework, or coded SVG artwork. Its claims are bounded to the public `1.0.0` setting-free contest skill and do not imply independently verified plugin installation.
