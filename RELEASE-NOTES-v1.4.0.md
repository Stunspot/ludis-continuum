# Ludis Continuum v1.4.0 release notes

Version 1.4.0 updates the accepted v1.3.0 Campaign Table promise.

## Updated

- Night Routes is the new dark default: mineral depth, directional copper light, smoked glass, ordered waypoints and legible working states.
- Patchwork World is a daylight material environment using moss, flax and restrained madder; it changes scene, cue, preparation and world-reading composition.
- The native editor now validates ledger drafts before leaving JSON tools and validates proposal edits before applying them.
- Saves reject deletion, demotion, or rewriting of existing active canon. Imports bind the preserved original bytes to the submitted ledger.
- Cue order, prep, session notes, proposal edits, comparison, import/export, player projection, conflicts and both themes were exercised through the browser and native API.

## Evidence boundary

The local verification exercised both themes at desktop and mobile widths, 126 native tests, native HTTP integrity cases, import/export round trips, and browser workflows. Fresh-host discovery, live-table usability, macOS, player-prose safety, rules accuracy and VTT import remain outside this evidence.
