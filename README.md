Ludis Continuum is a choice-shaped RPG and fiction engine for playable pressure, relationships, secrets, consequences, and live decisions.

This repository contains only the setting-free curated contest skill shipped with Nova, copied from the public Nova + MIND release into a fresh standalone history. Private development history and worked campaign worlds are excluded.
