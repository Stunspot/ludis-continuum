# Ludis Continuum v1.3.0 release notes

Version 1.3.0 re-derives the Campaign Table from the accepted v1.2.0 session-desk promise.

## Updated

- Tonight centers the actual pinned situation with its ordered cues, near horizon, preparation and explicit linked material visible together.
- World & relationships supports status- and source-aware reading, incoming/outgoing links, contradictions, and side-by-side comparison.
- At the table retains GM-only observation capture; native JSON, import/export and player reading remain available as advanced or separate surfaces.
- Keeper's folio and Theatre of choices are distinct responsive working environments sharing the same governed native ledger.
- Empty, loading, malformed-ledger, unsaved-draft and save-conflict states have clear recovery paths.

## Evidence boundary

The local browser review exercised both environments at desktop and 390px, native create/capture/save/pin/reload, and JSON draft navigation. The existing validator and approval tools remain authoritative. Live-table usability, fresh-host discovery, macOS behavior, player-prose safety, rules accuracy and VTT import are not established by this release.
